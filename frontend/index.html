מסד נתונים בענן (Firebase Cloud Firestore)

ממתין להגדרת מפתח

כל נתוני הסועדים, זמני הישיבה וההתראות יכולים להישמר ישירות בחשבון ה-Firebase שלך בענן, ללא תפיסת מקום בדיסק של המחשב.

כיצד לחבר את ה-Firebase שלך:
1. פתח פרויקט חדש ב-Firebase Console והפעל את Firestore Database.
2. עבור ל-Project Settings ← Service accounts ← לחץ Generate new private key.
3. שמור את קובץ ה-JSON בתיקייה: config/firebase_credentials.json.
המערכת תזהה את הקובץ אוטומטית ותסנכרן את כל הנתונים לענן!
